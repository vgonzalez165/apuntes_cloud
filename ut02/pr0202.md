## 1. Requisitos previos

Antes de iniciar la práctica recuerda que:

- Debes poner en marcha el laboratorio de AWS y actualizar los valores del token de sesión en el fichero `~/.aws/credentials`.
- Si no lo has hecho ya, debes instalar la librería `boto3` (`pip install boto3`)
- Al estar en el entorno de AWS Academy, debes utilizar siempre la región `us-east-1`.


## 2. Tareas a Desarrollar


### Tarea 1: Verificación de Identidad y Conexión Inicial

El objetivo de esta primera tarea es crear un script en Python que verifique si las credenciales de AWS Academy son válidas y liste los buckets existentes en la cuenta.

Los pasos que tienes que realizar son:

1. Consultar a AWS quién es el usuario autenticado para confirmar que el token no ha caducado.
2. Obtener y mostrar por pantalla la lista de buckets disponibles junto con su fecha de creación.
3. Si la cuenta no tiene ningún bucket, mostrar un mensaje informativo en lugar de dejar la salida vacía.

A continuación indico algunos consejos para realizar esta tarea:

- Vamos a utilizar dos servicios:
  - El **servicio S3** de almacenamiento de objetos, que se inicializa con la orden `boto3.client('s3', region_name='us-east-1')`.
  - El **servicio STS (Security Token Service)**, que sirve para obtener datos de autenticación y seguridad.
- Usa la librería STS para comprobar la identidad del usuario. El método `sts.get_caller_identity()` devuelve un diccionario del cual nos interesan los campos `'Account'` y `'Arn'`.
- Para obtener el listado de buckets la función que necesitamos es `s3.list_buckets()`. Devuelve un diccionario donde la clave relevante es `'Buckets'` (una lista de diccionarios con `'Name'` y `'CreationDate'`).
- Cuando trabajes con AWS es importante controlar las excepciones. Dos excepciones relevantes son:
  - `botocore.exceptions.NoCredentialsError`: si no se detectan credenciales.
  - `botocore.exceptions.ClientError`: captura fallos de AWS. Si el código de error (`e.response['Error']['Code']`) es `'ExpiredToken'`, muestra un mensaje claro indicando al usuario que debe renovar las credenciales en AWS Academy.


### Tarea 2: Aprovisionamiento de almacenamiento (Crear Bucket)

En esta segunda tareaa deberás crear bucket S3 aplicando las restricciones de nomenclatura del servicio.

Los requisitos que debe cumplir el script son:

1. El nombre del bucket debe cumplir la normativa de S3 (minúsculas, números, guiones) y ser **globalmente único**.
2. Para evitar colisiones con otros alumnos o usuarios de AWS en el mundo, el script debe generar el nombre combinando un prefijo identificativo del alumno con un identificador aleatorio.
3. Gestionar posibles errores si el nombre propuesto ya existe.


Algunos consejos para esta tarea:

- Puedes generar un identificador único usando el módulo estándar `uuid` (función `uuid.uuid4().hex[:6]`).
- El método para crear un bucket es `s3.create_bucket(Bucket=nombre_bucket)`.
- Para gestionar las excepciones debes capturar `ClientError` y comprobar si el código de error es `'BucketAlreadyExists'` o `'BucketAlreadyOwnedByYou'`.



### Tarea 3: Ingesta de archivos

En esta tarea debes subir un archivo local al bucket creado en la tarea anterior, organizándolo dentro de una "carpeta" lógica y asignándole metadatos.

Los requisitos funcionales del script son:

1. Generar mediante código un archivo de texto local (por ejemplo, un log simulado o un archivo de configuración del sistema).
2. Subir dicho archivo al bucket asignándole un nombre que simule una ruta de directorios (por ejemplo: `backups/servidor1/reporte.txt`).
3. Especificar explícitamente el tipo MIME (*Content-Type*) como `text/plain` durante la subida.


Algunas pautas para realizar esta tarea:

- Para escribir un archivo de texto usa las funciones estándar de Python `open()` y `write()`. A continuación tienes un ejemplo de código:

    ```python
    with open("informe.txt", "w", encoding="utf-8") as f:
        f.write("Línea 1: Estado del servicio activo\n")
        f.write("Línea 2: Uso de CPU normal\n")
    ```

- Para subir un archivo a un bucket usa la función `s3.upload_file()`. Los parámetros que requiere son `Filename` (ruta local), `Bucket` (nombre del bucket) y `Key` (ruta/nombre destino en S3).
- Para los metadatos HTTP: utiliza el argumento opcional `ExtraArgs={'ContentType': 'text/plain'}`.
- Captura posibles errores de archivo local no encontrado (`FileNotFoundError`) y errores de acceso/permisos de AWS (`ClientError`).



### Tarea 4: Auditoría y descarga

Crea un script que inspeccione el contenido de un bucket, muestre sus detalles técnicos y descargue un objeto al disco local.

Los requisitos funcionales serán:

1. Pedir al usuario el nombre del bucket a consultar.
2. Listar todos los objetos almacenados mostrando: nombre del objeto (*Key*), tamaño en Kilobytes y tipo de almacenamiento (*StorageClass*).
3. Seleccionar el primer objeto de la lista y descargarlo en la máquina local añadiéndole el prefijo `restaurado_` a su nombre original.
4. Validar tras la descarga que el archivo local existe y tiene un tamaño mayor a 0 bytes.

Consejos para realizar esta tarea:

- Puedes listar los objetos con la función `s3.list_objects_v2(Bucket=nombre_bucket)`. Ten en cuenta que si el bucket está vacío, la respuesta no incluirá la clave `'Contents'`. Debes comprobar si esa clave existe antes de intentar iterar sobre ella.
- Para descargar el fichero usa `s3.download_file(Bucket=..., Key=..., Filename=...)`.
- Para validar que la descarga se ha realizado usa el módulo `os.path` (funciones `os.path.basename()` para extraer el nombre del fichero sin las "carpetas" y `os.path.getsize()` para verificar el tamaño en disco).



### Tarea 5: Desaprovisionamiento y limpieza de recursos

Crea un script que elimine de forma segura los datos y el bucket para evitar consumo de saldo en el Learner Lab.

**Requisitos funcionales:**

1. S3 prohíbe eliminar un bucket si contiene objetos (`BucketNotEmpty`). El script debe automatizar el vaciado previo.
2. El script debe solicitar confirmación explícita por consola (`s/n`) antes de proceder al borrado.
3. Si el usuario confirma, debe:
    - Listar todos los objetos presentes en el bucket.
    - Eliminar cada objeto uno a uno (o por lotes).
    - Eliminar el bucket una vez haya quedado completamente vacío.

Consejos para realizar esta tarea:

- Para borrar objetos individuales usa la función `s3.delete_object(Bucket=..., Key=...)`.
- El contenedor lo puedes borrar con `s3.delete_bucket(Bucket=...)`.
